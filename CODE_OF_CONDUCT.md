# Código de conducta

Queremos que participar en este proyecto sea una experiencia respetuosa para todas las personas.

- Sé amable y tratá a los demás con respeto; criticá ideas y código, no personas.
- No se toleran el acoso, la discriminación, los insultos ni la publicación de datos privados de otras personas.
- Aceptá las críticas constructivas y explicá tus decisiones con paciencia, especialmente con quienes recién empiezan.

Los mantenedores pueden editar, ocultar o eliminar comentarios, issues y contribuciones que incumplan estas reglas,
y bloquear temporal o definitivamente a quien lo haga de forma reiterada.

Para reportar una conducta inapropiada, escribí a los mantenedores mediante un reporte privado en la pestaña **Security** del repositorio.

Adaptado del [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/), versión 2.1.
